# Text Message

Send a text message to a WhatsApp recipient through the CPaaS+ WhatsApp Wrapper API. Text messages can also include a link preview where supported by the request format.

## Endpoint

`POST /api/whatsapp/{Sender Hash}/messages`

## Authentication

Include a valid Bearer token in the `Authorization` header. See [Getting Started](getting-started) for authentication and sender configuration.

## Request headers

| Header | Value |
|---|---|
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
| `Authorization` | `Bearer <token>` |

## Request parameters

Submit the following fields in the JSON request body.

| Parameter | Required | Description |
|---|---|---|
| `messaging_product` | Yes | Fixed value `whatsapp`. |
| `recipient_type` | Optional | Fixed value `individual`; this is the default. |
| `to` | Yes | Recipient's WhatsApp number in international format, without a leading `+`. |
| `type` | Yes | Fixed value `text`. |
| `text.body` | Yes | Text content of the message. |
| `text.preview_url` | Optional | Controls link-preview behaviour when a URL is included in the message. |

## Example request

```bash
curl --location 'https://testqa.cpaas.globeteleservices.com/api/whatsapp/{Sender Hash}/messages' \
--header 'Accept: application/json' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {{Bearer Token}}' \
--data '{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919373084880",
  "type": "text",
  "text": {
    "preview_url": false,
    "body": "Hello! Your appointment is confirmed."
  }
}'
```

Replace `{Sender Hash}` and `{{Bearer Token}}` with the values assigned to your CPaaS+ account. Update `to` and `text.body` for the intended recipient and message.

## Important considerations

- The `to` field identifies the message recipient; do not include a leading plus sign.
- Use `text.body` for the message content.
- The `text.preview_url` field controls link-preview behaviour in the request.
- Free-form text messages are subject to Meta's 24-hour customer-service window. See [Integration Notes](integration-notes) for details.
