# Text Message

Send a text message to a WhatsApp recipient through the CPaaS+ WhatsApp Wrapper API. Text messages can include a URL, with link-preview behaviour controlled by the `text.preview_url` field.

## Endpoint

**Method:** `POST`

**Path:** `/api/whatsapp/{Sender Hash}/messages`

**Sandbox base URL:** `https://testqa.cpaas.globeteleservices.com`

Replace `{Sender Hash}` with the hash assigned to your registered WhatsApp sender.

## Authentication and headers

Every request requires a valid Bearer token generated in the **API** tab of the CPaaS+ Portal.

| Header | Value |
|---|---|
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
| `Authorization` | `Bearer <token>` |

## Request parameters

Submit the following fields in the JSON request body.

| Parameter | Required | Description |
|---|---|---|
| `messaging_product` | Yes | Fixed value `"whatsapp"`. |
| `recipient_type` | Optional | Fixed value `"individual"`; this is the default. |
| `to` | Yes | Recipient's WhatsApp number in international format, without a leading `+`. |
| `type` | Yes | Fixed value `"text"`. |
| `text.body` | Yes | Text content of the message. |
| `text.preview_url` | Optional | Controls link-preview behaviour when a URL is included in the message. |

## Example request

Use the following cURL command to send a text message. Replace `{Sender Hash}`, `{{Bearer Token}}`, the recipient number, and the message text with values for your integration.

```bash
curl --location 'https://testqa.cpaas.globeteleservices.com/api/whatsapp/{Sender Hash}/messages' \
--header 'Accept: application/json' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {{Bearer Token}}' \
--data '{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919373084880",
  "type": "text",
  "text": {
    "preview_url": false,
    "body": "Hello! Your appointment is confirmed."
  }
}'
```

## Important considerations

- The `to` field identifies the recipient and must use international number format without a leading `+`.
- Use `text.body` to specify the message content.
- The optional `text.preview_url` field controls link-preview behaviour.
- Free-form text messages are subject to Meta's 24-hour customer-service window. See [Integration Notes](integration-notes) for details.
