# Video Message

Send a video clip to a WhatsApp recipient using a media ID. You can include an optional caption displayed with the video.

## Endpoint

**Method:** `POST`

**Path:** `/api/whatsapp/{Sender Hash}/messages`

**Sandbox base URL:** `https://testqa.cpaas.globeteleservices.com`

Replace `{Sender Hash}` with the hash assigned to your registered WhatsApp sender.

## Authentication and headers

Every request requires a valid Bearer token generated in the **API** tab of the CPaaS+ Portal.

| Header | Value |
|---|---|
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
| `Authorization` | `Bearer <token>` |

The top-level `to` field must contain the recipient's WhatsApp number in international format, without a leading `+`.

## Request parameters

Submit the following fields in the JSON request body.

| Parameter | Required | Description |
|---|---|---|
| `messaging_product` | Yes | Fixed value `"whatsapp"`. |
| `recipient_type` | Optional | Fixed value `"individual"`; this is the default. |
| `to` | Yes | Recipient's WhatsApp number in international format, without a leading `+`. |
| `type` | Yes | Fixed value `"video"`. |
| `video.id` | Yes | Media ID returned by the Media Upload API. |
| `video.caption` | Optional | Text displayed with the video. |

## Example request

Use the following JSON as the request body. Replace the recipient number, media ID, and example caption with values for your integration.

```json
{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919373084880",
  "type": "video",
  "video": {
    "id": "1487009022497978",
    "caption": "A quick look at the product in action"
  }
}
```

## Before sending the request

Upload the video using the Media Upload API first. Use the media ID returned by that operation as the value of `video.id`.

## Important considerations

- The `video.id` field is required.
- The `video.caption` field is optional.
- The top-level `to` field must use international number format without a leading `+`.
- The 24-hour customer-service window applies to free-form video messages. See [Integration Notes](integration-notes) for details.
