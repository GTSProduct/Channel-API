# Media Handling

Media files must be uploaded separately before they can be sent in WhatsApp messages that require a media ID. Message requests use JSON, while media uploads use `multipart/form-data`.

## Message types that require a media ID

| Message type | Field containing the media ID |
|---|---|
| Audio | `audio.id` |
| Image | `image.id` |
| Video | `video.id` |
| Document | `document.id` |
| Sticker | `sticker.id` |

## Media upload workflow

1. Upload the media file using the Media Upload API.
2. Capture the media ID returned by the upload operation.
3. Send a `POST` request to `/api/whatsapp/{Sender Hash}/messages`.
4. Include the media ID in the corresponding field for the selected message type, such as `image.id` or `document.id`.

Refer to the individual message pages for their request parameters and examples.

## Media Upload API

The upload endpoint, multipart field names, file-size limits, supported MIME types, and sample upload request and response are not specified here. Verify these details against the applicable Media Upload API specification before implementing the upload request.

## Sticker requirements

Sticker files must use the WebP format, either static or animated, and comply with Meta's sticker size guidelines. Numeric size limits are not specified here.

## Media-related errors

**HTTP `413 Payload Too Large`** may occur when an uploaded media file exceeds the applicable size limit.

Refer to [Common HTTP Status Codes](../status-codes) for HTTP status codes, their meanings, and possible causes.
