# Location Message

Share a pinned location with a WhatsApp recipient using latitude and longitude coordinates. You can also include an optional location name and address.

## Endpoint

**Method:** `POST`

**Path:** `/api/whatsapp/{Sender Hash}/messages`

**Sandbox base URL:** `https://testqa.cpaas.globeteleservices.com`

Replace `{Sender Hash}` with the hash assigned to your registered WhatsApp sender.

## Authentication and headers

Every request requires a valid Bearer token generated in the **API** tab of the CPaaS+ Portal.

| Header | Value |
|---|---|
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
| `Authorization` | `Bearer <token>` |

The top-level `to` field must contain the recipient's WhatsApp number in international format, without a leading `+`.

## Request parameters

Submit the following fields in the JSON request body.

| Parameter | Required | Description |
|---|---|---|
| `messaging_product` | Yes | Fixed value `"whatsapp"`. |
| `to` | Yes | Recipient's WhatsApp number in international format, without a leading `+`. |
| `type` | Yes | Fixed value `"location"`. |
| `location.latitude` | Yes | Latitude coordinate of the location. |
| `location.longitude` | Yes | Longitude coordinate of the location. |
| `location.name` | Optional | Name or label associated with the location. |
| `location.address` | Optional | Address associated with the location. |

## Example request

Use the following JSON as the request body. Replace the recipient number, coordinates, and example location details with values for your integration.

```json
{
  "messaging_product": "whatsapp",
  "to": "919373084880",
  "type": "location",
  "location": {
    "latitude": 19.076090,
    "longitude": 72.877426,
    "name": "Mumbai",
    "address": "Maharashtra, Mumbai"
  }
}
```

## Important considerations

- Both `location.latitude` and `location.longitude` are required.
- The location name and address are optional.
- The top-level `to` field must use international number format without a leading `+`.
- The 24-hour customer-service window applies to free-form location messages. See [Integration Notes](integration-notes) for details.
