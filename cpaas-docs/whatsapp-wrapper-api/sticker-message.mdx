# Sticker Message

Send a static or animated WebP sticker to a WhatsApp recipient using a media ID.

## Endpoint

**Method:** `POST`

**Path:** `/api/whatsapp/{Sender Hash}/messages`

**Sandbox base URL:** `https://testqa.cpaas.globeteleservices.com`

Replace `{Sender Hash}` with the hash assigned to your registered WhatsApp sender.

## Authentication and headers

Every request requires a valid Bearer token generated in the **API** tab of the CPaaS+ Portal.

| Header | Value |
|---|---|
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
| `Authorization` | `Bearer <token>` |

The top-level `to` field must contain the recipient's WhatsApp number in international format, without a leading `+`.

## Request parameters

Submit the following fields in the JSON request body.

| Parameter | Required | Description |
|---|---|---|
| `messaging_product` | Yes | Fixed value `"whatsapp"`. |
| `recipient_type` | Optional | Fixed value `"individual"`; this is the default. |
| `to` | Yes | Recipient's WhatsApp number in international format, without a leading `+`. |
| `type` | Yes | Fixed value `"sticker"`. |
| `sticker.id` | Yes | Media ID returned by the Media Upload API. |

## Example request

Use the following JSON as the request body. Replace the recipient number and media ID with values for your integration.

```json id="p8m2vd"
{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919373084880",
  "type": "sticker",
  "sticker": {
    "id": "762449710003335"
  }
}
```

## Before sending the request

Upload the sticker file using the Media Upload API first. Use the media ID returned by that operation as the value of `sticker.id`.

## Important considerations

- Sticker files must use WebP format and can be static or animated.
- Sticker files must comply with Meta's sticker size guidelines.
- The `sticker.id` field is required.
- The 24-hour customer-service window applies to free-form sticker messages. See [Integration Notes](integration-notes) for details.
