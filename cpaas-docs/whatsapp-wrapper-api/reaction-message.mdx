# Reaction Message

React to a specific inbound or outbound WhatsApp message using a single emoji. You can also remove an existing reaction by sending an empty string in the emoji field.

## Endpoint

**Method:** `POST`

**Path:** `/api/whatsapp/{Sender Hash}/messages`

**Sandbox base URL:** `https://testqa.cpaas.globeteleservices.com`

Replace `{Sender Hash}` with the hash assigned to your registered WhatsApp sender.

## Authentication and headers

Every request requires a valid Bearer token generated in the **API** tab of the CPaaS+ Portal.

| Header | Value |
|---|---|
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
| `Authorization` | `Bearer <token>` |

The top-level `to` field must contain the recipient's WhatsApp number in international format, without a leading `+`.

## Request parameters

Submit the following fields in the JSON request body.

| Parameter | Required | Description |
|---|---|---|
| `messaging_product` | Yes | Fixed value `"whatsapp"`. |
| `recipient_type` | Optional | Fixed value `"individual"`; this is the default. |
| `to` | Yes | Recipient's WhatsApp number in international format, without a leading `+`. |
| `type` | Yes | Fixed value `"reaction"`. |
| `reaction.message_id` | Yes | WhatsApp message ID (`wamid`) of the message being reacted to. |
| `reaction.emoji` | Yes | A single emoji character. Use an empty string (`""`) to remove a reaction. |

## Example request

Use the following JSON as the request body. Replace the recipient number, message ID, and example emoji with values for your integration.

```json id="xqk28m"
{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919373084880",
  "type": "reaction",
  "reaction": {
    "message_id": "wamid.HBgMOTE5MzczMDg0ODgwFQIAERgSNThGNjk3RjVFOUQ2QzNCNDFGAA==",
    "emoji": "😀"
  }
}
```

## Important considerations

- The `reaction.message_id` field must identify the message being reacted to.
- The message ID (`wamid`) is available in the response to the original send request or through your inbound webhook.
- The `reaction.emoji` field accepts a single emoji character.
- To remove a reaction, set `reaction.emoji` to an empty string (`""`).
- The 24-hour customer-service window applies to free-form reactions. See [Integration Notes](integration-notes) for details.
