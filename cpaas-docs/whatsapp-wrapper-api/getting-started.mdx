# Build with the WhatsApp Wrapper API

The CPaaS+ WhatsApp Wrapper API provides endpoints for integrating WhatsApp messaging into your applications. This guide helps developers understand the available message types, interactive messaging capabilities, message interactions, and integration requirements.

Start with the Getting Started guide, then select the relevant API documentation to understand its endpoint, authentication, request parameters, and example requests.

## Integration essentials

| Concept | Description |
|---|---|
| Endpoint | Use the endpoint documented for the specific operation. |
| Authentication | Include the required Bearer token in the `Authorization` header. |
| Request format | Follow the endpoint's documented HTTP method, headers, and JSON body. |
| Sender identification | Use the registered sender's assigned hash wherever the endpoint requires it. |
| Troubleshooting | Consult the relevant API guide and status-code documentation when investigating errors. |

<Note>
Start with Getting Started, then open the guide for the message or interaction you want to implement. Use each endpoint's documentation as the source of truth for request fields and supported behaviour.
</Note>
