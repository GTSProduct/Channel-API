# Location Request Message

Ask a WhatsApp recipient to share their current location using an interactive location request prompt.

## Endpoint

**Method:** `POST`

**Path:** `/api/whatsapp/{Sender Hash}/messages`

**Sandbox base URL:** `https://testqa.cpaas.globeteleservices.com`

Replace `{Sender Hash}` with the hash assigned to your registered WhatsApp sender.

## Authentication and headers

Every request requires a valid Bearer token generated in the **API** tab of the CPaaS+ Portal.

| Header | Value |
|---|---|
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
| `Authorization` | `Bearer <token>` |

The top-level `to` field must contain the recipient's WhatsApp number in international format, without a leading `+`.

## Request parameters

Submit the following fields in the JSON request body.

| Parameter | Required | Description |
|---|---|---|
| `messaging_product` | Yes | Fixed value `"whatsapp"`. |
| `recipient_type` | Optional | Fixed value `"individual"`; this is the default. |
| `to` | Yes | Recipient's WhatsApp number in international format, without a leading `+`. |
| `type` | Yes | Fixed value `"interactive"`. |
| `interactive.type` | Yes | Fixed value `"location_request_message"`. |
| `interactive.body.text` | Yes | Prompt text explaining why the recipient is being asked to share their location. |
| `interactive.action.name` | Yes | Fixed value `"send_location"`. |

## Example request

Use the following JSON as the request body. Replace the recipient number and example text with values for your integration.

```json
{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919373084880",
  "type": "interactive",
  "interactive": {
    "type": "location_request_message",
    "body": {
      "text": "Let's start with your pickup point — please share your current location."
    },
    "action": {
      "name": "send_location"
    }
  }
}
```

## Important considerations

- The request uses `type: "interactive"` and `interactive.type: "location_request_message"`.
- The `interactive.body.text` field contains the prompt shown to the recipient.
- The `interactive.action.name` field must be `"send_location"`.
- The 24-hour customer-service window applies to free-form interactive messages. See [Integration Notes](integration-notes) for details.
