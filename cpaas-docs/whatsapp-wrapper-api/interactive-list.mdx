# Interactive Message — List

Send an interactive WhatsApp message containing a scrollable list of options grouped into sections. The recipient can open the list and select a row.

## Endpoint

**Method:** `POST`

**Path:** `/api/whatsapp/{Sender Hash}/messages`

**Sandbox base URL:** `https://testqa.cpaas.globeteleservices.com`

Replace `{Sender Hash}` with the hash assigned to your registered WhatsApp sender.

## Authentication and headers

Every request requires a valid Bearer token generated in the **API** tab of the CPaaS+ Portal.

| Header | Value |
|---|---|
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
| `Authorization` | `Bearer <token>` |

The top-level `to` field must contain the recipient's WhatsApp number in international format, without a leading `+`.

## Request parameters

Submit the following fields in the JSON request body.

| Parameter | Required | Description |
|---|---|---|
| `messaging_product` | Yes | Fixed value `"whatsapp"`. |
| `recipient_type` | Optional | Fixed value `"individual"`; this is the default. |
| `to` | Yes | Recipient's WhatsApp number in international format, without a leading `+`. |
| `type` | Yes | Fixed value `"interactive"`. |
| `interactive.type` | Yes | Fixed value `"list"`. |
| `interactive.header.text` | Optional | Header text displayed above the body. |
| `interactive.body.text` | Yes | Main message text. |
| `interactive.footer.text` | Optional | Text displayed below the body. |
| `interactive.action.button` | Yes | Label on the button that opens the list. |
| `interactive.action.sections` | Yes | Array of sections. Each section contains a title and rows with `id`, `title`, and `description`. |

## Example request

Use the following JSON as the request body. Replace the recipient number and example values with values for your integration.

```json
{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919373084880",
  "type": "interactive",
  "interactive": {
    "type": "list",
    "header": {
      "type": "text",
      "text": "Choose Shipping Option"
    },
    "body": {
      "text": "Which shipping option do you prefer?"
    },
    "footer": {
      "text": "CPaaS+: reliable delivery, every time"
    },
    "action": {
      "button": "Shipping Options",
      "sections": [
        {
          "title": "I want it ASAP!",
          "rows": [
            {
              "id": "priority_express",
              "title": "Priority Mail Express",
              "description": "Next Day to 2 Days"
            },
            {
              "id": "priority_mail",
              "title": "Priority Mail",
              "description": "1-3 Days"
            }
          ]
        },
        {
          "title": "I can wait a bit",
          "rows": [
            {
              "id": "ground_advantage",
              "title": "Ground Advantage",
              "description": "2-5 Days"
            },
            {
              "id": "media_mail",
              "title": "Media Mail",
              "description": "2-8 Days"
            }
          ]
        }
      ]
    }
  }
}
```

## Important considerations

- Each row has an `id`, a `title`, and a `description`.
- The `interactive.action.button` value is the label used to open the list.
- The 24-hour customer-service window applies to free-form interactive messages. See [Integration Notes](integration-notes) for details.

## Responses and errors

Refer to [Common HTTP Status Codes](../status-codes) for HTTP status codes, their meanings, and possible causes.

A successful response does not necessarily mean the recipient received the message.
