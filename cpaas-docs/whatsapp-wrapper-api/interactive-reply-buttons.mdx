# Interactive Message — Reply Buttons

Send an interactive WhatsApp message with up to three quick-reply buttons, allowing the recipient to respond with a single tap.

## Endpoint

**Method:** `POST`

**Path:** `/api/whatsapp/{Sender Hash}/messages`

**Sandbox base URL:** `https://testqa.cpaas.globeteleservices.com`

Replace `{Sender Hash}` with the hash assigned to your registered WhatsApp sender.

## Authentication and headers

Every request requires a valid Bearer token generated in the **API** tab of the CPaaS+ Portal.

| Header | Value |
|---|---|
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
| `Authorization` | `Bearer <token>` |

The top-level `to` field must contain the recipient's WhatsApp number in international format, without a leading `+`.

## Request parameters

Submit the following fields in the JSON request body.

| Parameter | Required | Description |
|---|---|---|
| `messaging_product` | Yes | Fixed value `"whatsapp"`. |
| `recipient_type` | Optional | Fixed value `"individual"`; this is the default. |
| `to` | Yes | Recipient's WhatsApp number in international format, without a leading `+`. |
| `type` | Yes | Fixed value `"interactive"`. |
| `interactive.type` | Yes | Fixed value `"button"`. |
| `interactive.header` | Optional | Header object. Supported header types include text, image, video, and document. |
| `interactive.body.text` | Yes | Main message text. |
| `interactive.footer.text` | Optional | Text displayed below the body. |
| `interactive.action.buttons` | Yes | Array of up to three reply button objects. Each button uses `type: "reply"` and a nested `reply` object containing `id` and `title`. |

## Example request

Use the following JSON as the request body. Replace the recipient number, media ID, and example values with values for your integration.

```json
{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919373084880",
  "type": "interactive",
  "interactive": {
    "type": "button",
    "header": {
      "type": "image",
      "image": {
        "id": "762449710003335"
      }
    },
    "body": {
      "text": "Your appointment is scheduled for 9am tomorrow. Use the buttons if you need to reschedule."
    },
    "footer": {
      "text": "CPaaS+ Appointments"
    },
    "action": {
      "buttons": [
        {
          "type": "reply",
          "reply": {
            "id": "change-button",
            "title": "Change"
          }
        },
        {
          "type": "reply",
          "reply": {
            "id": "cancel-button",
            "title": "Cancel"
          }
        }
      ]
    }
  }
}
```

## Important considerations

- You can include up to three quick-reply buttons in a message.
- Each button has an `id` to identify the selected option and a `title` displayed to the recipient.
- The example uses an image header and two reply buttons.
- The 24-hour customer-service window applies to free-form interactive messages. See [Integration Notes](integration-notes) for details.
