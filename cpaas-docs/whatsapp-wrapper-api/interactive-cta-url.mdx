# Interactive Message — Call-To-Action URL

Send an interactive WhatsApp message with a header, body, optional footer, and a button that opens an external URL when tapped.

## Endpoint

**Method:** `POST`

**Path:** `/api/whatsapp/{Sender Hash}/messages`

**Sandbox base URL:** `https://testqa.cpaas.globeteleservices.com`

Replace `{Sender Hash}` with the hash assigned to your registered WhatsApp sender.

## Authentication and headers

Every request requires a valid Bearer token generated in the **API** tab of the CPaaS+ Portal.

| Header | Value |
|---|---|
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
| `Authorization` | `Bearer <token>` |

The top-level `to` field must contain the recipient's WhatsApp number in international format, without a leading `+`.

## Request parameters

Submit the following fields in the JSON request body.

| Parameter | Required | Description |
|---|---|---|
| `messaging_product` | Yes | Fixed value `"whatsapp"`. |
| `to` | Yes | Recipient's WhatsApp number in international format, without a leading `+`. |
| `type` | Yes | Fixed value `"interactive"`. |
| `interactive.type` | Yes | Fixed value `"cta_url"`. |
| `interactive.header` | Optional | Header object. Supported header types described in the guide include text, image, video, and document. |
| `interactive.body.text` | Yes | Main message text. |
| `interactive.footer.text` | Optional | Text displayed below the body. |
| `interactive.action.name` | Yes | Fixed value `"cta_url"`. |
| `interactive.action.parameters.display_text` | Yes | Text displayed on the URL button. |
| `interactive.action.parameters.url` | Yes | URL opened when the button is tapped. |

## Example request

Use the following JSON as the request body. Replace the example recipient, image link, and destination URL with values for your integration.

```json id="n8v4ky"
{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919373084880",
  "type": "interactive",
  "interactive": {
    "type": "cta_url",
    "header": {
      "type": "image",
      "image": {
        "link": "https://picsum.photos/200/300"
      }
    },
    "body": {
      "text": "Tap the button below to see available dates."
    },
    "action": {
      "name": "cta_url",
      "parameters": {
        "display_text": "See Dates",
        "url": "https://www.example.com?clickID=kqDGWd24Q5TRwoEQTICY7W1J"
      }
    },
    "footer": {
      "text": "Dates subject to change."
    }
  }
}
```

## Notes

- Supported header types include text, image, video, and document.
- The `display_text` value is the label shown on the button; the `url` value is the destination opened when the recipient taps it.
- The 24-hour customer-service window applies to free-form interactive messages. See [Integration Notes](integration-notes) for details.

## Responses and errors

The documentation provides a common HTTP status-code table rather than a separate response-body example for this message type.

Refer to [Common HTTP Status Codes](../status-codes) for the documented status codes, meanings, and possible causes. An HTTP success status indicates that the message was accepted for processing or delivery; it does not by itself confirm receipt by the recipient.
