# Document Message

Send a PDF or another document file to a WhatsApp recipient through the CPaaS+ WhatsApp Wrapper API. The request references the document by its media ID and can include an optional filename and caption.

## Endpoint

**Method:** `POST`

**Path:** `/api/whatsapp/{Sender Hash}/messages`

**Sandbox base URL:** `https://testqa.cpaas.globeteleservices.com`

Replace `{Sender Hash}` with the hash assigned to your registered WhatsApp sender.

## Authentication and headers

Every request requires a valid Bearer token generated in the **API** tab of the CPaaS+ Portal.

| Header | Value |
|---|---|
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
| `Authorization` | `Bearer <token>` |

## Request parameters

Submit the following fields in the JSON request body.

| Parameter | Required | Description |
|---|---|---|
| `messaging_product` | Yes | Fixed value `"whatsapp"`. |
| `recipient_type` | Optional | Fixed value `"individual"`; this is the default. |
| `to` | Yes | Recipient's WhatsApp number in international format, without a leading `+`. |
| `type` | Yes | Fixed value `"document"`. |
| `document.id` | Yes | Media ID returned by the Media Upload API. |
| `document.filename` | Optional | Filename shown to the recipient. |
| `document.caption` | Optional | Text shown beneath the document. |

## Example request

Use the following JSON as the request body. Replace the sender hash, token, recipient number, media ID, and example document details with values for your integration.

```json id="7x4m1p"
{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919373084880",
  "type": "document",
  "document": {
    "id": "1452039652685523",
    "filename": "invoice.pdf",
    "caption": "Your order confirmation (PDF)"
  }
}
```

## Before sending the request

Upload the document using the Media Upload API first. Use the media ID returned by that operation as the value of `document.id`.

The Media Upload API's endpoint and request specification are not detailed on this page. Refer to the applicable media-upload documentation for those steps.

## Important considerations

- Use the sender hash assigned to your WhatsApp sender in the request URL.
- Pass the top-level recipient number in international format without a leading `+`.
- The `document.id` field is required; `document.filename` and `document.caption` are optional.
- The 24-hour customer-service window applies to free-form document messages. See [Integration Notes](integration-notes) for details.

## Responses and errors

The documentation provides a common HTTP status-code table rather than a separate response-body example for this message type.

Refer to [Common HTTP Status Codes](../status-codes) for the documented status codes, meanings, and possible causes. An HTTP success status indicates that the message was accepted for delivery; it does not by itself confirm receipt by the recipient.
