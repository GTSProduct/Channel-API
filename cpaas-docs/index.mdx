## Integration essentials

| Concept | Detail |
| --- | --- |
| Base URL | Use the CPaaS+ API host assigned to your account. |
| Authentication | Include a Bearer token with every authenticated request. See [Authentication](/authentication). |
| Request format | Use JSON request bodies with `Content-Type: application/json`, unless an endpoint specifies otherwise. |
| Templates | Where required, create templates in the CPaaS+ web portal and obtain approval before sending. |
| Delivery status | Consult the relevant channel's status endpoint and the [Status Codes and Errors](/errors) guide. |

<Note>
  New to the API? Start with the [Quickstart](/quickstart). The **API Reference** tab contains the endpoint-level documentation and interactive playground, where available.
</Note>
