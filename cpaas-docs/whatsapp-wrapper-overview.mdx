# WhatsApp Wrapper API

The CPaaS+ WhatsApp Wrapper API provides a unified interface for sending supported WhatsApp messages through a common REST endpoint. It enables applications to deliver text, media, interactive content, location information, and other supported messaging experiences through a configured WhatsApp sender.

## Capabilities

| Category | Supported functionality |
|---|---|
| Text and media | Text, image, audio, video, document, and sticker messages |
| Contact and location | Contact cards, location messages, and location requests |
| Interactive messaging | Reply buttons, interactive lists, and CTA URL messages |
| Message interactions | Reactions and contextual replies |
| Messaging controls | Typing indicators and read receipts, where supported |

## API Endpoint

**Method:** `POST`

**Path:** `/api/whatsapp/{senderHash}/messages`

The endpoint accepts requests for supported message types. The request body and required fields depend on the message type being sent.

## Authentication

Requests require a valid Bearer token in the `Authorization` header. The request must also include the appropriate `senderHash`, which identifies the configured WhatsApp sender.

## Request Format

Requests use JSON payloads. Each message type has its own schema and field requirements; refer to the corresponding endpoint documentation for request structures and examples.

## Media Messages

Image, audio, video, document, and sticker messages are subject to the applicable media requirements. Complete any required media preparation or upload steps before submitting a message request. Refer to the media handling documentation for details supported by your CPaaS+ configuration.
