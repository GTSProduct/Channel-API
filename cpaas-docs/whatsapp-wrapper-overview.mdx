# WhatsApp Wrapper API

The CPaaS+ WhatsApp Wrapper API lets your application send supported WhatsApp message types through a common API endpoint.

## What you can do

- Send text messages
- Send media messages, including images, audio, video, documents, and stickers
- Send contact and location information
- Send interactive messages, including buttons, lists, and CTA URLs
- Send reactions and contextual replies
- Manage read receipts and typing indicators, where supported by the API

## API endpoint

`POST /api/whatsapp/{senderHash}/messages`

## Before you begin

You need a valid bearer token and the appropriate `senderHash` for your WhatsApp sender configuration.

For media messages, follow the media requirements documented for your CPaaS+ account.
