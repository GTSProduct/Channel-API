---
title: "Delete a WhatsApp Flow"
description: "Delete a WhatsApp Flow."
---
Deletes the specified WhatsApp Flow.

## Endpoint

`DELETE {{base_url}}/api/whatsapp/{{meta_hash}}/flows/{{flow_id}}`

## Path parameters

| Parameter | Description |
|---|---|
| `meta_hash` | Meta account identifier used in the request URL. |
| `flow_id` | ID of the Flow to delete. |

## Request headers

| Header | Value |
|---|---|
| `Authorization` | `Bearer {{access_token}}` |

## Example request

```bash
curl --location --request DELETE 'https://testqa.gtsstaging.com/api/whatsapp/1ce8726a-2fe9-41e1-aa5f-1de62039d8c8/flows/1087009486941723' \
--header 'Authorization: Bearer 01a014f3-e2a6-7394-9517-faa82399c57c|HRPemWFfN4Aa9plmgYcEgnm3aghwuA8w9c04b952c'

```
