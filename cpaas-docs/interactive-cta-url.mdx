# Interactive Message — Call-To-Action URL

Send a message with a header, body, footer, and a single tappable button that opens an external URL.

## Endpoint

```http
POST /api/whatsapp/{Sender Hash}/messages
```

**Sandbox base URL:** `https://testqa.cpaas.globeteleservices.com`

## Common headers

```http
Accept: application/json
Content-Type: application/json
Authorization: Bearer <token>
```

The Bearer token is generated in the CPaaS+ Portal under the API tab. Replace `{Sender Hash}` with the registered sender hash obtained from the WhatsApp channel's Numbers section. The guide says the top-level `to` value should use international format without a leading `+`.

## Parameters

| Parameter | Required | Description from the guide |
|---|---|---|
| `messaging_product` | Yes | Fixed value `"whatsapp"`. |
| `to` | Yes | Recipient WhatsApp number, without a leading `+`. |
| `type` | Yes | Fixed value `"interactive"`. |
| `interactive.type` | Yes | Fixed value `"cta_url"`. |
| `interactive.header` | Optional | Text, image, video, or document header object. |
| `interactive.body.text` | Yes | Main message text. |
| `interactive.footer.text` | Optional | Small text below the body. |
| `interactive.action.parameters.display_text` | Yes | Text shown on the button. |
| `interactive.action.parameters.url` | Yes | URL opened when the button is tapped. |

## Request example

Use the following JSON as the request body. Replace the sender hash, token, recipient, IDs, and example values with values for your integration.

```json
{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919373084880",
  "type": "interactive",
  "interactive": {
    "type": "cta_url",
    "header": { "type": "image", "image": { "link": "https://picsum.photos/200/300" } },
    "body": { "text": "Tap the button below to see available dates." },
    "action": {
      "name": "cta_url",
      "parameters": {
        "display_text": "See Dates",
        "url": "https://www.example.com?clickID=kqDGWd24Q5TRwoEQTICY7W1J"
      }
    },
    "footer": { "text": "Dates subject to change." }
  }
}
```

## Notes

The sample header uses an image link. The guide allows text, image, video, or document header objects, but does not enumerate all object schemas on this page.

## Responses and errors

The source guide provides a common HTTP status-code table rather than a separate response body for this message type. See [Common HTTP Status Codes](../status-codes) for the documented meanings and possible causes. A success status indicates acceptance for delivery and does not guarantee that the recipient received the message.
