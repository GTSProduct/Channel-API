# Interactive Message — Call-To-Action URL

Send an interactive WhatsApp message with a header, body, optional footer, and a button that opens an external URL.

## Endpoint

```http
POST /api/whatsapp/{Sender Hash}/messages
```

**Sandbox base URL:** `https://testqa.cpaas.globeteleservices.com`

## Headers

```http
Accept: application/json
Content-Type: application/json
Authorization: Bearer <token>
```

Generate the Bearer token from the **API** tab in the CPaaS+ Portal. Replace `{Sender Hash}` with the registered sender hash available under **Numbers** in the WhatsApp channel.

Pass the recipient's WhatsApp number in international format without the leading `+` sign.

## Parameters

| Parameter | Required | Description |
|---|---|---|
| `messaging_product` | Yes | Fixed value: `"whatsapp"`. |
| `to` | Yes | Recipient's WhatsApp number without a leading `+` sign. |
| `type` | Yes | Fixed value: `"interactive"`. |
| `interactive.type` | Yes | Fixed value: `"cta_url"`. |
| `interactive.header` | Optional | Header object. The reference lists text, image, video, and document headers. |
| `interactive.body.text` | Yes | Main message text. |
| `interactive.footer.text` | Optional | Footer text displayed below the body. |
| `interactive.action.parameters.display_text` | Yes | Text displayed on the button. |
| `interactive.action.parameters.url` | Yes | URL opened when the button is tapped. |

## Request Example

```json
{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919373084880",
  "type": "interactive",
  "interactive": {
    "type": "cta_url",
    "header": {
      "type": "image",
      "image": {
        "link": "https://picsum.photos/200/300"
      }
    },
    "body": {
      "text": "Tap the button below to see available dates."
    },
    "action": {
      "name": "cta_url",
      "parameters": {
        "display_text": "See Dates",
        "url": "https://www.example.com?clickID=kqDGWd24Q5TRwoEQTICY7W1J"
      }
    },
    "footer": {
      "text": "Dates subject to change."
    }
  }
}
```

Replace the example recipient number, image URL, button text, and destination URL with values for your integration.

## Notes

The example uses an image header. The reference also lists text, video, and document headers but does not provide their full request schemas on this page.

## Responses and Errors

Refer to [Common HTTP Status Codes](../status-codes) for status code meanings and possible causes.

A successful response indicates that the request was accepted for processing; it does not guarantee delivery to the recipient.
