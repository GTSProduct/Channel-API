---
title: "Assign Assets to a WhatsApp Flow"
description: "Assign assets to a WhatsApp Flow."
---
Assigns the supplied asset details to a WhatsApp Flow.

## Endpoint

`POST {{base_url}}/api/whatsapp/{{sender_hash}}/flows/{{flow_id}}/assets`

## Path parameters

| Parameter | Description |
|---|---|
| `sender_hash` | Sender identifier used in the request URL. |
| `flow_id` | ID of the Flow to which the assets are assigned. |

## Request headers

| Header | Value |
|---|---|
| `Content-Type` | `application/json` |
| `Authorization` | `Bearer {{access_token}}` |

## Example request

```bash
curl --location 'https://testqa.gtsstaging.com/api/whatsapp/1ce8726a-2fe9-41e1-aa5f-1de62039d8c8/flows/4551273491813916/assets' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer 01a014f3-e2a6-7394-9517-faa82399c57c|HRPemWFL1N4Aa9plmgYcEgnm3aghwuA8w9c04b952c' \
--data '{
  "name": "survey3",
  "categories": ["SURVEY"],
  "languages": ["en"]  }'

}'
```

## Request body

| Parameter | Description |
|---|---|
| `name` | Name of the Flow. |
| `categories` | Array containing the Flow category. |
| `languages` | Array containing the Flow language. |
