# Fetch WhatsApp Message Templates

Retrieves WhatsApp message templates. The `name` query parameter is used to request a specific template by name.

## Endpoint

`GET {{base_url}}/api/whatsapp/{{sender_hash}}/message_templates?name={{template_name}}`

## Path parameters

| Parameter | Description |
|---|---|
| `sender_hash` | Sender identifier used in the request URL. |

## Query parameters

| Parameter | Description |
|---|---|
| `name` | Name of the template to fetch. |

## Request headers

| Header | Value |
|---|---|
| `Accept` | `application/json` |
| `Authorization` | `Bearer {{access_token}}` |

## Example request

```bash
curl --location '{{base_url}}/api/whatsapp/{{sender_hash}}/message_templates?name={{template_name}}' \
--header 'Accept: application/json' \
--header 'Authorization: Bearer {{access_token}}'
```
