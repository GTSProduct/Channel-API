# Deprecate a WhatsApp Flow

Deprecates the specified WhatsApp Flow.

## Endpoint

`POST {{base_url}}/api/whatsapp/{{meta_hash}}/flows/{{flow_id}}/deprecate`

## Path parameters

| Parameter | Description |
|---|---|
| `meta_hash` | Meta account identifier used in the request URL. |
| `flow_id` | ID of the Flow to deprecate. |

## Request headers

| Header | Value |
|---|---|
| `Authorization` | `Bearer {{access_token}}` |

## Example request

```bash
curl --location --request POST '{{base_url}}/api/whatsapp/{{meta_hash}}/flows/{{flow_id}}/deprecate' \
--header 'Authorization: Bearer {{access_token}}'
```
