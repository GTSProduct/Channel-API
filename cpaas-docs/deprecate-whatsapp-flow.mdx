---
title: "Deprecate a WhatsApp Flow"
description: "Deprecate a WhatsApp Flow."
---
Deprecates the specified WhatsApp Flow.

## Endpoint

`POST {{base_url}}/api/whatsapp/{{meta_hash}}/flows/{{flow_id}}/deprecate`

## Path parameters

| Parameter | Description |
|---|---|
| `meta_hash` | Meta account identifier used in the request URL. |
| `flow_id` | ID of the Flow to deprecate. |

## Request headers

| Header | Value |
|---|---|
| `Authorization` | `Bearer {{access_token}}` |

## Example request

```bash
curl --location --request POST 'https://testqa.gtsstaging.com/api/whatsapp/1ce8726a-2fe9-41e1-aa5f-1de62039d8c8/flows/1485024240191958/deprecate' \
--header 'Authorization: Bearer 01a014f3-e2a6-7394-9517-faa82399c57c|HRPemWFfN4Aa9plmgYcEgnm3aghwuA8w9c04b952c'

```
