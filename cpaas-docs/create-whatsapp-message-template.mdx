---
title: "Create a WhatsApp Message Template"
description: "Guide to creating a WhatsApp message template."
---
This guide explains how to create a WhatsApp message template for a specified sender using the CPaaS+ API.

## Endpoint

`POST {{base_url}}/api/whatsapp/{{sender_hash}}/message_templates`

## Path parameters

| Parameter | Description |
|---|---|
| `sender_hash` | Sender identifier used in the request URL. |

## Request headers

| Header | Value |
|---|---|
| `Content-Type` | `application/json` |
| `Authorization` | `Bearer {{access_token}}` |

## Request body

The request body contains the template name, language, category and components.

| Parameter | Description |
|---|---|
| `name` | Name of the WhatsApp message template. |
| `language` | Language code for the template. |
| `category` | Template category, such as `MARKETING`. |
| `components` | Array containing the template components, such as HEADER, BODY, FOOTER and BUTTONS. |

## Example request

```bash
curl --location '{{base_url}}/api/whatsapp/{{sender_hash}}/message_templates' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {{access_token}}' \
--data '{
  "name": "api_custom_message121",
  "language": "en",
  "category": "MARKETING",
  "components": [
    {
      "type": "HEADER",
      "format": "TEXT",
      "text": "Our {{1}} is on!",
      "example": {
        "header_text": [
          "Summer Sale"
        ]
      }
    },
    {
      "type": "BODY",
      "text": "Shop now through {{1}} and use code {{2}} to get {{3}} off of all merchandise.",
      "example": {
        "body_text": [
          [
            "the end of August",
            "25OFF",
            "25%"
          ]
        ]
      }
    },
    {
      "type": "FOOTER",
      "text": "Use the buttons below to manage your marketing subscriptions"
    },
    {
      "type": "BUTTONS",
      "buttons": [
        {
          "type": "QUICK_REPLY",
          "text": "Unsubcribe from Promos"
        },
        {
          "type": "QUICK_REPLY",
          "text": "Unsubscribe from All"
        },
        {
          "type": "QUICK_REPLY",
          "text": "Reply button 3"
        },
        {
          "type": "QUICK_REPLY",
          "text": "Reply button 4"
        }
      ]
    }
  ]
}'
```

## Template components

The example request contains four component types:

- **HEADER:** Displays the template header. This example uses a text header with a variable.
- **BODY:** Contains the main message text and three example variables.
- **FOOTER:** Displays additional text at the bottom of the message.
- **BUTTONS:** Defines quick-reply buttons included in the template.
