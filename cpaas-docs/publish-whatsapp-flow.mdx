description: "Publish a WhatsApp Flow."
---
Publishes the specified WhatsApp Flow.

## Endpoint

`POST {{base_url}}/api/whatsapp/{{meta_hash}}/flows/{{flow_id}}/publish`

## Path parameters

| Parameter | Description |
|---|---|
| `meta_hash` | Meta account identifier used in the request URL. |
| `flow_id` | ID of the Flow to publish. |

## Request headers

| Header | Value |
|---|---|
| `Content-Type` | `application/json` |
| `Authorization` | `Bearer {{access_token}}` |

## Example request

```bash
curl --location 'https://testqa.gtsstaging.com/api/whatsapp/1ce8726a-2fe9-41e1-aa5f-1de62039d8c8/flows/4551273491813916/publish' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer 01a014f3-e2a6-7394-9517-faa82399c57c|HRPemWFfN4Aa9plmgYcEgnm3aghwuA8w9c04b952c' \
--data '{
}'

```

The supplied example sends an empty JSON object as the request body.
