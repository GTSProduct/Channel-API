# Create a WhatsApp Flow

Creates a WhatsApp Flow using its name, category and language.

## Endpoint

`POST {{base_url}}/api/whatsapp/{{sender_hash}}/flows`

## Path parameters

| Parameter | Description |
|---|---|
| `sender_hash` | Sender identifier used in the request URL. |

## Example request

```bash
curl --location '{{base_url}}/api/whatsapp/{{sender_hash}}/flows' \
--data '{
  "name": "survey3",
  "categories": ["SURVEY"],
  "languages": ["en"]
}'
```

## Request body

| Parameter | Description |
|---|---|
| `name` | Name of the Flow. |
| `categories` | Array containing the Flow category. |
| `languages` | Array containing the Flow language. |
