# Media Handling

Media files are uploaded separately and referenced by media ID when sending a message. Media upload uses `multipart/form-data`; message requests use JSON.

## Message types that require a media ID

| Message type | Field containing the media ID |
|---|---|
| Audio | `audio.id` |
| Image | `image.id` |
| Video | `video.id` |
| Document | `document.id` |
| Sticker | `sticker.id` |

## Documented workflow

1. Upload the media file using the Media Upload API.
2. Capture the returned media ID.
3. Send a `POST` request to `/api/whatsapp/{Sender Hash}/messages`.
4. Put the media ID in the relevant field for the selected message type.


## Sticker note

The guide says sticker files must be static or animated WebP and follow Meta's sticker size guidelines. It does not provide numeric size limits in the supplied PDF.

## Media-related errors

HTTP `413 Payload Too Large` is a possible response when an uploaded media file exceeds Meta's size limit for its type. It does not provide numeric size limits. See [Common HTTP Status Codes](../status-codes).
