# Interactive Message — Reply Buttons

Send a message with up to three quick-reply buttons. The recipient can respond by selecting a button.

## Endpoint

```http
POST /api/whatsapp/{Sender Hash}/messages
```

**Sandbox base URL:** `https://testqa.cpaas.globeteleservices.com`

## Headers

```http
Accept: application/json
Content-Type: application/json
Authorization: Bearer <token>
```

Generate the Bearer token from the **API** tab in the CPaaS+ Portal. Replace `{Sender Hash}` with the registered sender hash available under **Numbers** in the WhatsApp channel.

Pass the recipient's WhatsApp number in international format without the leading `+` sign.

## Parameters

| Parameter | Required | Description |
|---|---|---|
| `messaging_product` | Yes | Fixed value: `"whatsapp"`. |
| `to` | Yes | Recipient's WhatsApp number without a leading `+` sign. |
| `type` | Yes | Fixed value: `"interactive"`. |
| `interactive.type` | Yes | Fixed value: `"button"`. |
| `interactive.header` | Optional | Header object. The reference lists text, image, video, and document headers. |
| `interactive.body.text` | Yes | Main message text. |
| `interactive.footer.text` | Optional | Footer text displayed below the body. |
| `interactive.action.buttons` | Yes | Array of up to three reply button objects. Each button uses `type: "reply"` and a `reply` object containing `id` and `title`. |

## Request Example

```json
{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919373084880",
  "type": "interactive",
  "interactive": {
    "type": "button",
    "header": {
      "type": "image",
      "image": {
        "id": "762449710003335"
      }
    },
    "body": {
      "text": "Your appointment is scheduled for 9am tomorrow. Use the buttons if you need to reschedule."
    },
    "footer": {
      "text": "CPaaS+ Appointments"
    },
    "action": {
      "buttons": [
        {
          "type": "reply",
          "reply": {
            "id": "change-button",
            "title": "Change"
          }
        },
        {
          "type": "reply",
          "reply": {
            "id": "cancel-button",
            "title": "Cancel"
          }
        }
      ]
    }
  }
}
```

Replace the example recipient number, media ID, button IDs, and message text with values for your integration.

## Notes

The request example contains two quick-reply buttons. Up to three buttons are supported, as specified in the reference.

## Responses and Errors

Refer to [Common HTTP Status Codes](../status-codes) for status code meanings and possible causes.

A successful response indicates that the request was accepted for processing; it does not guarantee delivery to the recipient.
