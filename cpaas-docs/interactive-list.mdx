# Interactive Message — List

Send a message with a scrollable list of options grouped into sections. The recipient can select one row from the list.

## Endpoint

```http
POST /api/whatsapp/{Sender Hash}/messages
```

**Sandbox base URL:** `https://testqa.cpaas.globeteleservices.com`

## Headers

```http
Accept: application/json
Content-Type: application/json
Authorization: Bearer <token>
```

Generate the Bearer token from the **API** tab in the CPaaS+ Portal. Replace `{Sender Hash}` with the registered sender hash available under **Numbers** in the WhatsApp channel.

Pass the recipient's WhatsApp number in international format without the leading `+` sign.

## Parameters

| Parameter | Required | Description |
|---|---|---|
| `messaging_product` | Yes | Fixed value: `"whatsapp"`. |
| `to` | Yes | Recipient's WhatsApp number without a leading `+` sign. |
| `type` | Yes | Fixed value: `"interactive"`. |
| `interactive.type` | Yes | Fixed value: `"list"`. |
| `interactive.header.text` | Optional | Header text displayed above the message body. |
| `interactive.body.text` | Yes | Main message text. |
| `interactive.footer.text` | Optional | Footer text displayed below the body. |
| `interactive.action.button` | Yes | Button label used to open the list. |
| `interactive.action.sections` | Yes | Array of sections. Each section has a title and rows containing `id`, `title`, and `description`. |

## Request Example

```json
{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919373084880",
  "type": "interactive",
  "interactive": {
    "type": "list",
    "header": {
      "type": "text",
      "text": "Choose Shipping Option"
    },
    "body": {
      "text": "Which shipping option do you prefer?"
    },
    "footer": {
      "text": "CPaaS+: reliable delivery, every time"
    },
    "action": {
      "button": "Shipping Options",
      "sections": [
        {
          "title": "I want it ASAP!",
          "rows": [
            {
              "id": "priority_express",
              "title": "Priority Mail Express",
              "description": "Next Day to 2 Days"
            },
            {
              "id": "priority_mail",
              "title": "Priority Mail",
              "description": "1-3 Days"
            }
          ]
        },
        {
          "title": "I can wait a bit",
          "rows": [
            {
              "id": "ground_advantage",
              "title": "Ground Advantage",
              "description": "2-5 Days"
            },
            {
              "id": "media_mail",
              "title": "Media Mail",
              "description": "2-8 Days"
            }
          ]
        }
      ]
    }
  }
}
```

Replace the example recipient number and sample values with the values for your integration.
