# Interactive Message — List

Send a message with a scrollable list of options grouped into sections, letting the recipient pick one row.

## Endpoint

```http
POST /api/whatsapp/{Sender Hash}/messages
```

**Sandbox base URL:** `https://testqa.cpaas.globeteleservices.com`

## Common headers

```http
Accept: application/json
Content-Type: application/json
Authorization: Bearer <token>
```

The Bearer token is generated in the CPaaS+ Portal under the API tab. Replace `{Sender Hash}` with the registered sender hash obtained from the WhatsApp channel's Numbers section. The guide says the top-level `to` value should use international format without a leading `+`.

## Parameters

| Parameter | Required | Description from the guide |
|---|---|---|
| `messaging_product` | Yes | Fixed value `"whatsapp"`. |
| `to` | Yes | Recipient WhatsApp number, without a leading `+`. |
| `type` | Yes | Fixed value `"interactive"`. |
| `interactive.type` | Yes | Fixed value `"list"`. |
| `interactive.header.text` | Optional | Short header shown above the body. |
| `interactive.body.text` | Yes | Main message text. |
| `interactive.footer.text` | Optional | Small text below the body. |
| `interactive.action.button` | Yes | Label of the button that opens the list. |
| `interactive.action.sections` | Yes | Array of sections, each with a title and rows containing `id`, `title`, and `description`. |

## Request example

Use the following JSON as the request body. Replace the sender hash, token, recipient, IDs, and example values with values for your integration.

```json
{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919373084880",
  "type": "interactive",
  "interactive": {
    "type": "list",
    "header": { "type": "text", "text": "Choose Shipping Option" },
    "body": { "text": "Which shipping option do you prefer?" },
    "footer": { "text": "CPaaS+: reliable delivery, every time" },
    "action": {
      "button": "Shipping Options",
      "sections": [
        {
          "title": "I want it ASAP!",
          "rows": [
            { "id": "priority_express", "title": "Priority Mail Express", "description": "Next Day to 2 Days" },
            { "id": "priority_mail", "title": "Priority Mail", "description": "1-3 Days" }
          ]
        },
        {
          "title": "I can wait a bit",
          "rows": [
            { "id": "ground_advantage", "title": "Ground Advantage", "description": "2-5 Days" },
            { "id": "media_mail", "title": "Media Mail", "description": "2-8 Days" }
          ]
        }
      ]
    }
  }
}
```

## Responses and errors
See [Common HTTP Status Codes](../status-codes) for the documented meanings and possible causes. A success status indicates acceptance for delivery and does not guarantee that the recipient received the message.
